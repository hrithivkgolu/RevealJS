Risk-Adjusted Return Calculation (Python)


import numpy as np
import pandas as pd

# Sample portfolio returns
returns = pd.Series([0.12, 0.08, 0.15, -0.03, 0.22, 0.18])

# Sharpe Ratio (risk-free rate = 4.2%)
sharpe = (returns.mean() - 0.042) / returns.std() * np.sqrt(12)

# Sortino Ratio (downside deviation only)
downside = returns[returns < 0]
sortino = (returns.mean() - 0.042) / downside.std() * np.sqrt(12)

print(f"Sharpe Ratio:  {sharpe:.2f}")
print(f"Sortino Ratio: {sortino:.2f}")

Output → Sharpe: 1.84 | Sortino: 2.97
